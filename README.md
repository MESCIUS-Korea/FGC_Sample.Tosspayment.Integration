# Forguncy 토스페이먼츠(Toss Payments) 연동 데모

Forguncy(노코드 플랫폼)에 **토스페이먼츠(Toss Payments)** 결제를 연동한 데모입니다.
코딩 없이 외부 결제 서비스를 연동해 결제창 호출부터 결제 승인까지 처리하는 방법을 확인할 수 있습니다.

## 🔗 데모 바로가기

👉 [데모 실행하기](https://demo.forguncy.co.kr/tosspayment)

## 🧩 핵심 포인트: 외부 결제 API 연동

- 상품/주문 정보 입력 후 결제 요청
- 토스페이먼츠 결제창 호출 및 결제 진행
- 결제 승인 API 호출(Post 데이터 명령)로 결제 결과 처리
- 결제 결과(성공/실패)를 데이터 테이블에 저장

## 📋 주요 기능

- 주문 정보 입력 및 결제 요청
- 토스페이먼츠 결제 위젯/결제창 연동
- 결제 성공·실패 처리
- 결제 내역 조회

## ℹ️ Forguncy란?

Forguncy는 코딩 없이 드래그 앤 드롭 방식으로 웹 애플리케이션을 만들 수 있는 MESCIUS의 노코드 개발 플랫폼입니다. 토스페이먼츠 외에도 카카오맵 등 다양한 외부 API 서비스와 연동한 시스템을 손쉽게 구축할 수 있습니다.
